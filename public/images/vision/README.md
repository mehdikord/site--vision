# تصاویر محلی ویژن

این پوشه شامل تصاویر نمونه‌ای است که در صفحات سایت، محصولات و نمونه‌کارهای اولیه استفاده شده‌اند. فایل‌ها از Pexels دریافت و برای سرعت سایت به WebP تبدیل شده‌اند. نام هر فایل شامل شناسهٔ تصویر اصلی است؛ برای مثال `pexels-photo-8082312.webp`.

تصاویر اسلایدر تا عرض ۲۴۰۰ پیکسل و سایر تصاویر تا عرض ۱۶۰۰ پیکسل ذخیره شده‌اند. سایت از طریق مسیر `/images/vision/نام-فایل.webp` به آن‌ها دسترسی دارد.

تصاویر نمونه، عکس پروژه‌های واقعی ویژن نیستند و می‌توانند با تصاویر تأییدشدهٔ کارفرما جایگزین شوند. پیش از استفادهٔ نهایی، شرایط [مجوز Pexels](https://www.pexels.com/license/) را بررسی کنید.
